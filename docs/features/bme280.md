# BME280 (firmware)

Sister docs: [Node-RED](../../nodered/node-red-contrib-de-esp32/docs/bme280.md) · [Manager](../../manager/docs/bme280.md)

Framework (add/remove, NVS, validation): [modules.md](modules.md).

## What it does
Module type `bme280`: a Bosch BME280 temperature / pressure / humidity sensor on I2C. It samples on a fixed period and publishes a reading when it moves or when the sensor goes ok/not ok. Two sensors can share one bus with different addresses.

## How it works on the ESP
- Native ESP-IDF `i2c_master` driver; Bosch integer compensation lives in the file. No Adafruit/Arduino code.
- Bus `i2c0` or `i2c1`, 100 kHz (`kHz`). The first claim sets SDA/SCL/Hz and creates the master bus (`resource_i2c_claim`); later devices must match all three. Both pins are owned by `bus_<bus>`; there is no `mod_<id>` GPIO owner.
- Pins (`kPins`): `sda` and `scl`, both required, `share:"bus"`, cap `out`. Board default `i2c0`: SDA 21, SCL 22. Internal pull-ups are weak; use the breakout's 4.7 kΩ.
- Apply: soft reset (0xE0 ← 0xB6), read chip id (0xD0). Not `0x60` (for example a BMP280 `0x58`) logs a warning and the instance stays configured with `ok:false`. If the id matches, calibration is loaded and `ctrl_hum`/`config`/`ctrl_meas` written. Standby is fixed at t_sb=5 (1000 ms) in normal mode.
- One poll task (`bme_poll`, 4096 bytes stack, prio 5) wakes every 50 ms and samples each sensor once per `sample_ms`. In `forced` mode it triggers a measurement and waits ~50 ms (+20 ms if still measuring).
- A sample of `0x80000` (skipped measurement) is treated as a failed read. Humidity is clamped to 0-100.
- Bus event is sent when `ok` flips, or T moves ≥ 0.10 °C, P ≥ 0.50 hPa or RH ≥ 0.50 %. State (`mod_<id>`) is updated every sample.
- Limits: max 2 sensors (`kMax`); addresses `0x76`/`0x77` only; no BMP280/BME680 type.
- Unclear: with a non-0x60 chip in `forced` mode, `sample()` still triggers and reads with no calibration loaded, so `ok` could flip to true with meaningless values. Not verified on hardware.

## Settings
Stored in the instance's `settings` object (`kSettings`), validated by the module framework:

| Field | Type / range | Default | Notes |
|---|---|---|---|
| `addr` | enum `118` (0x76), `119` (0x77) | `118` | SDO low/high; unique per bus |
| `sample_ms` | int 200-10000 | `1000` | poll period |
| `osrs_t` | enum 1, 2, 4, 8, 16 | `1` | temperature oversampling |
| `osrs_p` | enum 1, 2, 4, 8, 16 | `1` | pressure oversampling |
| `osrs_h` | enum 1, 2, 4, 8, 16 | `1` | humidity oversampling |
| `filter` | enum 0, 2, 4, 8, 16 | `0` | IIR filter coefficient, 0 = off |
| `mode` | enum `normal`, `forced` | `normal` | |

Numbers may be sent as numbers or numeric strings; they are saved as numbers. Out-of-range or unknown values are refused (not clamped). Other instance fields: `id` (prefix `env`), `bus` (default `i2c0`), `pins`, `enabled`, `delivery` (default `latest`). Saved in NVS `components`/`modules`; applied immediately and at boot.

## Commands
Only the generic module commands:

```json
{"cmd":"module.add","type":"bme280","id":"env0","bus":"i2c0","pins":{"sda":21,"scl":22},"settings":{"addr":118,"sample_ms":1000,"osrs_t":1,"osrs_p":1,"osrs_h":1,"filter":0,"mode":"normal"}}
```
```json
{"cmd":"module.configure","id":"env0","settings":{"addr":118,"sample_ms":5000,"osrs_t":2,"osrs_p":2,"osrs_h":1,"filter":4,"mode":"forced"}}
```
`settings` replaces the whole object; keys left out go back to their defaults. `module.cmd` → `module has no commands`.

Driver errors: `bme280 id, sda, and scl required`, `bme280 addr must be 0x76 or 0x77`, `bme280 already applied`, `bme280 limited to 2 instances`, resource errors (`unknown i2c bus (use i2c0 or i2c1)`, `i2c <bus> hz must be 100000 or 400000`, pin mismatch, owned-by), and the framework's `i2c address must be unique on this bus`.

## Events and state
State key `mod_<id>`, event bus topic `io/env`:

```json
{"topic":"io/env","data":{"id":"env0","type":"bme280","ok":true,"addr":118,"t_c":22.53,"p_hpa":1013.25,"rh":45.1}}
```

| Field | Notes |
|---|---|
| `ok` | last sample read fine |
| `addr` | 118 or 119 |
| `t_c` | °C, 2 decimals; only when `ok` |
| `p_hpa` | hPa, 2 decimals; only when `ok` |
| `rh` | %RH, 1 decimal; only when `ok` |

Seen on WS `/api/v1/ws`, MQTT `{root}/{topic_id}/io`, `GET /api/v1/pins`, `module.list` `state`, `io.hydrate`. Delivery class `latest` by default (QoS 0 / droppable under MQTT backlog).
