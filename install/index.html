de-esp32 install

Plug in a classic ESP32 DevKitC. Chrome or Edge flashes it over USB, then sets the device name and Wi-Fi on the serial console.

This page needs the Web Serial API. Open it in Chrome or Edge over localhost or HTTPS.

Or ask the board. This does not scan Wi-Fi from this computer. It talks to the plugged-in ESP over USB and fills the network name above. The board must already be running this firmware.
