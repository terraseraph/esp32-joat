Workshop node (fresh backup) → Greenhouse

This is a dry run. Nothing has been changed yet. Steps are applied in this order.

1Remove rules:none

2Remove add-ons:none (env0 BME280 already matches → reconfigure)

3Turn off pins

  • −GPIO 16 (Output)

4Set pins

  • +GPIO 2 Output
  • +GPIO 4 Output (invert off, start High)
  • +GPIO 13 Input (debounce 50 ms)
  • +GPIO 32 and GPIO 34 Analog (ADC) (sample 50 ms, hysteresis 20 mV, smoothing 70 %)
  • +GPIO 25 PWM (5000 Hz, duty 350)
  • +GPIO 26 Servo (90°, 500–2500 µs)

5Add add-ons

  • ~env0 BME280 (I²C i2c0, SDA 21, SCL 22) reconfigureSame id and type, settings re-applied.
  • +rfid0 RC522 (SPI vspi, CS 5) Conflict. GPIO 27 is used by add-on env1 on Greenhouse, which isn't being removed — rfid0's RST pin can't be set. Fix: untick Add-ons or remove env1 first.

6Add rules

  • +r32 When GPIO 32 > 1000 mV set GPIO 4 On, otherwise Off
  • +r13 When GPIO 13 is High set GPIO 25 (PWM) to 80 %, otherwise 0 %

Not changed: MQTT broker, device name.
